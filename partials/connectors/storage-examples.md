# Document stores

Examples of the document store a firm may keep its files in. This plugin ships a connector for each of them:

- Google Drive
- Box
- Dropbox
- Microsoft 365

Any one of them can be the firm's document store. The list gives examples, not a preference.

The list says which stores exist, never which are connected. Whether a store is connected in this session is settled only by looking for its tools, so never report a store as connected or not connected because it appears here.
