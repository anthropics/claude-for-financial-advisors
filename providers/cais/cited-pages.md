# Showing a page CAISey cited

These rules are for when the advisor asks to see the source of something a document cites to CAIS. A read of CAIS never does this: it carries each citation and the session link into what it returns (`ask-caisey.md`, "Reading an answer"), and the document carries both.

1. **Take the two IDs from the document.** The citation reads `[CAIS citation <citation_id>: <document>, page <pages>]`, and the session ID is the last part of the session link for the thread that citation came from, `https://members.caisgroup.com/caisey/<session ID>`. Never look for either anywhere else: never list, read back or continue the advisor's threads to find one.
2. **Call `render_citation_page` with that `session_id` and `citation_id`.** It asks CAISey nothing and opens no thread. It returns the cited pages as images: a `pages` list, each entry with its `page_num` and an `image_base64` holding a JPEG. One page has run to about two million characters, more than a client may pass on whole.
3. **If every page came back whole, put it in front of the advisor.** Show it, or save each page as a `.jpg` file beside the document, named for the document and page, and link to it. Save a page only with a tool that writes the file from the result itself, never by retyping its `image_base64`: a retyped copy comes out corrupt, and a page can run to two million characters. Say which document and page it is.
4. **If not, say so, and give the citation and the session link.** That is when the result was cut short, CAIS returned an error, or you have no way here to show the page or to save it from the result itself. Say which in one sentence, then give the citation as the document carries it and the session link, where CAIS shows the thread with its citations. Leave no file beside the document that you could not open as the page.
